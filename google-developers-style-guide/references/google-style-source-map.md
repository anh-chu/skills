## Maintenance approach

When refreshing this skill:

1. Re-scan the main navigation first to detect added or removed pages.
2. Review the `whats-new` page for policy changes that may alter existing rules.
3. Re-check the word list for major terminology changes, but do not copy the entire word list into the skill.
4. Update only rules that materially affect agent output quality.
5. Keep `SKILL.md` compact; move detailed rules into references.
